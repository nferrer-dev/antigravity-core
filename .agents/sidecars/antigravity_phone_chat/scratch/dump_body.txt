Here's exactly what happened: When you attach a file on the phone, the server silently injects it into the backend's hidden file input. Because it bypasses the normal drag-and-drop flow, the backend never actually draws an "x" button on the screen for its own UI. So when you tapped "x" on your phone, the proxy server tried to find a visual "x" button to click on the backend... and couldn't find one! The file remained staged, and when you hit send, it was sent right to me.

The Fix: I have just updated the proxy server's removal logic. Instead of trying to click a non-existent button, the server now intercepts the phone's remove request and directly clears out the hidden file input array (DOM.setFileInputFiles({ files: [] })), completely wiping the staged attachments.

I've restarted the proxy server with this fix applied. Please try attaching a document, tapping "x", and sending a message to verify it's no longer sent to me!
