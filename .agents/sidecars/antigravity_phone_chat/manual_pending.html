The reason the Edit and Redirect icons were only appearing on sent messages (and not pending messages) is due to a structural difference in how the Antigravity Desktop app renders them in the DOM.

Sent messages have a specific button container class (.user-input-buttons-container) which my previous script was explicitly looking for to inject the buttons. However, pending messages do not have this container class. They just render a standalone Trash Can button beside the text. Since the script couldn't find the expected container on pending messages, it simply skipped injecting the Edit/Redirect buttons, leaving only the original Trash Can.

I have updated the injection script in the phone UI proxy (app_v8.js) to handle this.
