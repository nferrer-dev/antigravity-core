# Edge Cases & Heuristics: coherence-bake

- **Zero Invented Problems on `AIRTIGHT_HALT`**: When `coherence_bake_gate.py` returns `"status": "AIRTIGHT_HALT"`, you MUST immediately stop proposing architectural abstractions, micro-optimizations, or cosmetic refactors and present the `certificate_sha256` proof to the user.
- **Empirical Baseline Mandate for `SYSTEM_DESIGN` and `OPTIMIZATION`**: Never mark `measurable_gain_above_epsilon: true` for a design or optimization finding unless `reproducible_check` demonstrates a concrete asymptotic reduction, query-plan index hit, lock-contention removal, or complexity drop on an active execution path.
- **Path Traversal and Line-Range Verification**: Every `file_and_line` entry must resolve strictly inside `--repo-root` with 1-indexed `start_line <= end_line <= total_file_lines`, or `coherence_bake_gate.py` will deterministically reject the finding.
- **Air-Gapped SOTA Retrieval Hygiene**: Research subagents gathering `SOTA_BENCHMARK` citations must never execute shell commands or mutate Cortex memory, and `coherence_bake_gate.py` automatically rejects findings containing invisible Unicode codepoints or Markdown image exfiltration links.
- **UTF-8 LF Serialization for Gate Artifacts**: Always write `stage0_coherence_bake_ast.json`, `stage0_coherence_bake_z3.json`, and `coherence_bake_findings.json` using explicit UTF-8 without BOM and LF line endings so `coherence_bake_gate.py` and `sha256_anchor` checks remain platform-deterministic.
- **Exhaustive Phase 1 Sweep and Closed-Loop Re-Audit**: Never artificially cap Phase 1 discovery at 3 findings; audit all schema columns, API response invariants, and the full test suite upfront, and after Phase 5 implementation automatically re-run the full repository test suite and live invariant audit in a closed loop until zero actionable findings remain (`AIRTIGHT_HALT`) before yielding to the user.
- **4-Surface Matrix & Anti-Self-Confirmation Gate (`Kamoi et al., TACL 2024`)**: When passing a JSON object to `coherence_bake_gate.py`, `exhaustiveness_manifest` is mandatory and must certify `independent_redteam_reaudit: true` alongside all 4 `surfaces_audited` booleans (`config_to_runtime_hooks`, `prompt_to_gate_schemas`, `single_to_multi_composition`, `cross_tree_and_doc_parity`); an implementing agent must never self-certify `findings: []` without an independent zero-shared-context red-team re-audit.
- **Clean-Round Unanchored Falsification & Transcript Introspection (`Huang et al., ICLR 2024`)**: Never declare `AIRTIGHT_HALT` on the same pass that modified repository files (`verified_findings_count > 0`); always execute a clean post-fix round where the Red-Team Auditor receives zero anchoring about prior fixes, emits a valid Stage 5 `<RUBRIC_SCORE>` block (`AIRTIGHT_HALT` or `PROCEED_FIX`), and has zero `status: ERROR` or `BLOCKED by BRC` hook rejections in its execution transcript.
- **Tri-State Gate, 100% File Coverage Ledger, & Mandatory Disk Proofs (`INCOMPLETE_AUDIT_RETRY`)**: `coherence_bake_gate.py` refuses both `PROCEED_FIX` and `AIRTIGHT_HALT` (returning `INCOMPLETE_AUDIT_RETRY`, exit code `2`) if `file_coverage_ledger` omits any scannable repository file or has a stale SHA-256 digest, or if `PROCEED_FIX` omits any deterministic surface gap detected by `--audit-repo` (`unreported_surface_gaps`), and requires disk-verified `wave_history`, `redteam_receipt_path`, and `redteam_transcript_path` before granting `AIRTIGHT_HALT`.
