# Learned Edge Cases

- **Agent Capability Scoping**: Claude Code has no per-agent capability flags; capability is controlled by the role prompt and tool access of each Task call, and no configuration can grant a subagent the ability to spawn its own subagents — which is exactly why this engine is flattened, with the parent making every spawn. Default explorer and debater agents MUST be read-only (Read/Grep/Glob only); a read-only agent asked to execute an empirical PoC, write files, or commit memories will stall or silently fail. Spawn a read-write agent ONLY when the Phase 3 empirical gate requires it, scope its writes strictly to the throwaway git worktree (never the primary checkout), and keep all `mcp__cortex__store_memory` ingestion in the parent so a missing or misconfigured MCP server degrades gracefully instead of blocking a shard.
